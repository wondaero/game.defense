# 디펜스 설계 (현재 기준)

> 지금 기준의 규칙만 적는다. 논의 과정·바뀐 이력은 [worklog.md](worklog.md), 처음 방향은 [game.war/docs/defense-start.md](game.war/docs/defense-start.md), 특수능력 원문은 [spec](spec).
> 표시: **확정** = 사용자가 정함 / *임시* = 제가 넣은 추천값, 사용자 확인 전 / 미정 = 아직 안 정함.
> 마지막 정리: 2026-11-26

## 1. 게임 성격 (확정)
- **혼자 하는 디펜스.** 다른 사람과 직접 붙는 대결은 없음 (defense-start.md 의 "같은 웨이브 대결" 계획은 취소)
  - 예전 밸런스 목표 "실력이 같으면 좋은 캐릭 쪽이 67% 승"도 대결이 없어 기준에서 뺌
- 다른 사람과는 두 가지만: **기록 공유**("몇 탄까지 깼다"), **캐릭 거래**
- 핵심 재미: 추측 대신 **계획**, 시간 압박 대신 **내 속도**. 탄의 몬스터·능력을 미리 다 보고 배치
- 계산은 고정 틱 + 정수 + 탄 번호 시드 → **같은 배치면 항상 같은 결과** (서버가 다시 돌려 기록 검증)

## 2. 판 · 진행 (확정)
- 판 7열 × 10행, 칸마다 길 또는 배치 칸. 맵은 글자 그림 데이터 (`packages/defense/src/maps.ts`)
  - 지그재그(길 39 · 배치 31, 쉬움), M자(길 43 · 배치 27, 어려움). 5탄마다 번갈아
- 몬스터는 길 위를 끊김 없이 이동 (위치 = 길 위 거리). 칸은 배치·사거리 계산용. 겹칠 수 있음, 빠른 몬스터는 앞지름
- 화면 흐름: **탄 고르기 → 탄 준비(출연 몬스터·능력치·특수능력 보고 덱 배치, 시간 제한 없음) → 게임 시작(자동 진행, 일시정지·배속) → 결과**
- 출전 6명 (*임시*, 설정에서 변경), 같은 그림은 한 명만, 한 칸에 한 명
- 목숨 20, 몬스터가 출구에 가면 깎임. 0이 되면 실패
- 공격 대상: 사거리 안에서 가장 앞선(출구에 가까운) 몬스터. 사거리 모양 마름모 (*임시*, 설정에 사각형)

## 3. 탄 (확정 + 임시 수치)
- **1~100탄 + 101탄부터 무한.** 공식으로 생성 (`stages.ts`). **70탄쯤 엄청 어렵게**
- 10탄마다 우두머리 탄 (일반 몬스터 60% + 우두머리)
- *임시 수치:* 체력 1.02배 복리, 방어 +1/10탄, 마릿수 10→35, 3탄부터 날쌘돌이, 6탄부터 단단이, 몬스터 민첩 25탄마다 +1
- 난이도 확인(`SIM=1 npx vitest run`, 특수능력 없음·단순 배치): 평균 덱 ~35탄, 능력치 최고 덱 ~54탄

## 4. 캐릭
### 기본 능력치 (확정: 4개를 각각 따로 균등하게 뽑음)
| 능력치 | 범위 | 비고 |
|---|---|---|
| 공격력 | 10~30 (*임시*) | 피해 = 공격력 − 몬스터 방어력 (최소 1) |
| 사거리 | 1~2칸 (*임시*) | |
| 공속(공격 간격) | 0.6~1.5초, 0.1초 단위 (*임시*) | |
| 민첩 | **5~10 (확정)** | 레벨업으로 11~13까지 |

### 민첩 (확정)
- **명중률 = 내 민첩 ÷ (내 민첩 + 몬스터 민첩).** 몬스터 입장에선 회피율. 예) 나 11 · 몬스터 8 → 11/19 ≈ 58%
- 몬스터 기술(얼리기)을 피할 확률도 같은 식 (*임시 해석*)
- 화면엔 "민첩 N"만 표시 (몬스터별 명중률 표시는 안 함)

### 특수능력 (확정, 원문 [spec](spec))
- 캐릭당 **0~1개**, 붙을 확률 **30%** (30~40% 중, 설정에서 변경). 붙으면 6종 **균등**, 수치도 각각 **균등**
- 모두 **공격할 때 발동, 빗나가도 발동**. 쿨타임은 능력 종류마다 고정

| # | 능력 | 뽑는 수치 | 쿨타임 |
|---|---|---|---|
| 1 | 스턴 | 확률 5/10/15% · 시간 0.5/1/1.5초 | 3초 |
| 2 | 광역공격 (맞힌 자리 중심 3×3) | 확률 3/5% | 없음 |
| 3 | 2배 데미지 (공격력×2 − 방어력) | 확률 5/10% | 없음 |
| 4 | 장애물 추가 (길 무작위 칸, 중첩 안 됨) | 확률 5/10% · 종류(가시/늪) | 판당 1회 |
| 5 | 출발지로 보내기 (우두머리도, 면역이면 안 됨) | 확률 3/5% | 20초 |
| 6 | 아군 전체 레벨업 | 확률 5% · 능력치(공격력/사거리/공속/민첩/전체) · +1/+2/+3 | 30초 |

- *임시 값:* 스턴 풀린 뒤 1초 면역 · 가시 = 1초마다 놓은 캐릭 공격력 50%(방어 무시) · 늪 = 속도 −40% · 장애물은 탄 끝까지 · 레벨업 5초, 1단계 = 공격력 +2 / 사거리 +1(3단계 +2) / 공격 간격 −0.1초 / 민첩 +1

## 5. 몬스터
| 종류 | 특징 | 민첩 (*임시*) |
|---|---|---|
| 보통 | 기본 | 5 |
| 날쌘돌이 | 빠름·민첩 높음 | 9 |
| 단단이 | 느림·방어 높음, 놓치면 목숨 −2 | 3 |
| 우두머리 | 크고 단단, 놓치면 목숨 −5 | 6 |

- 몬스터는 캐릭을 때려 쓰러뜨리지 않음 (캐릭 체력 없음). **방해만** (확정)
- 몬스터 "면역" 성질 칸 있음 (지금은 아무도 없음)
### 몬스터 특수능력
- 확정: 몬스터에도 특수능력이 있고, 탄 준비 화면에 공개. **얼리기** = 지나간 칸 주변 캐릭이 몇 초 공격 못 함
- 구현된 2종 (*임시 수치*): 단단해지기(맞으면 3초 방어력 +, 쿨 10초), 얼리기(1칸 안 캐릭 2초, 쿨 6초, 풀린 캐릭 3초 면역, 60탄부터 2칸)
- 등장 단계 (*임시*): 1~9탄 우두머리만 / 10~29 한 종류 / 30~49 두 종류 / 50~69 전 종류 1개 / 70~ 전 종류 전부
- 미정: 나머지 목록 (사용자가 줄 예정). 후보: 회피 상승·돌진·보호막·재생·분열·부활·잠복 / 치유·수호·지휘·소환 / 봉인·둔화·도발 / 스턴·감속·광역 면역

## 6. 성장 · 뽑기 · 변경 (확정)
- 강해지는 길 세 가지: **탄 보상**(캐릭 추가권·변경권·화폐 등) · **광고 보상** · **과금**. 모아서 원할 때 씀
- **캐릭 추가권** = 뽑기 1번
- 변경권은 둘로 나뉨. 그림은 늘 그대로

| 권 | 하는 일 |
|---|---|
| 능력치 변경권 · 보통 | 4개 전부 다시 |
| 능력치 변경권 · 고급 | 1개 골라 유지 + 3개 다시 |
| 능력치 변경권 · 최고급 | 2개 골라 유지 + 2개 다시 |
| 능력치 변경권 · 럭키 | 능력치마다 두 번 굴려 좋은 쪽 (최대치 그대로). **지금은 안 만듦, 자리만** |
| 특수능력 변경권 | 특수능력만 다시 (6종·수치 새로). 없어지지 않음. **특수능력 없는 캐릭엔 못 씀** |

- 특수능력 없는 캐릭에 능력치 변경권을 쓰면 **5%** 확률로 특수능력이 생김 → 6종 균등(각 1/6) → 수치도 하나씩 균등
- 모든 뽑기·변경 무작위는 **균등**
- 미정: 탄 보상 표(첫 클리어/반복, 우두머리 탄), 광고 하루 횟수, 화폐 종류, 보관함 크기, 거래 규칙(수수료·제한)

## 7. 서버 (방향 확정, 미구현)
- 서버가 가지는 것: 캐릭 목록 · 화폐 · 권
- 뽑기·변경 난수는 **서버에서** (앱에서 굴리면 조작 가능)
- 탄 결과는 앱이 **탄 번호 + 배치**만 보냄 → 서버가 같은 엔진으로 다시 돌려 판정·보상
- 광고 보상은 광고 회사의 서버 확인으로만 지급, 거래도 서버에서
- 예전 프로젝트의 Supabase 구조(`game.war/supabase`, `game.war/apps/mobile/src/online`) 참고. 비밀 키는 절대 앱·커밋에 넣지 않음

## 8. 그림 (확정: 그림은 코드로 그려 스프라이트로)
- `scripts/sprites/art.mjs` 에 SVG 코드로 그림 → `npm run sprites` 로 시트(PNG) 생성 → 게임이 개체마다 따로 애니메이션
- 지금 그림(동물 8종·몬스터 4종)은 **가능성 확인용 임시 그림.** 사용자가 그림 가이드를 주면 다시 그림
- 성능: 200개 60fps, 1000개 60fps, 2000개 29fps (PC 크롬). 휴대폰은 확인 전
