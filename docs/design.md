# 디펜스 설계 (현재 기준)

> 지금 기준의 규칙만 적는다. 논의 과정·바뀐 이력은 [worklog.md](worklog.md), 처음 방향은 [game.war/docs/defense-start.md](game.war/docs/defense-start.md), 특수능력 원문은 [spec](spec).
> 표시: **확정** = 사용자가 정함 / *임시* = 제가 넣은 추천값, 사용자 확인 전 / 미정 = 아직 안 정함.
> 마지막 정리: 2026-11-26

## 1. 게임 성격 (확정)
- **혼자 하는 디펜스.** 다른 사람과 직접 붙는 대결은 없음 (defense-start.md 의 "같은 웨이브 대결" 계획은 취소)
  - 예전 밸런스 목표 "실력이 같으면 좋은 캐릭 쪽이 67% 승"도 대결이 없어 기준에서 뺌
- 다른 사람과는 두 가지만: **기록 공유**("몇 탄까지 깼다"), **캐릭 거래**
- 핵심 재미: 추측 대신 **계획**, 시간 압박 대신 **내 속도**. 탄의 몬스터·능력을 미리 다 보고 배치
- 계산은 고정 틱 + 정수 + 씨앗 → **같은 배치 + 같은 판 씨앗이면 항상 같은 결과** (서버가 다시 돌려 기록 검증)
  - **판 씨앗은 판(도전)마다 새로 정함** (확정 2026-11-27): 같은 탄을 다시 해도 명중·특수능력 발동·장애물 자리가 달라짐. 서버 검증 땐 탄 번호 + 배치 + 판 씨앗을 보냄
  - 체력 보정(`npm run calibrate`)은 판 씨앗 0(탄 번호만)으로 고정해서 계산

## 2. 판 · 진행 (확정)
- 판 **7열 × 9행** (확정 2026-11-27, 예전 7×10). 칸마다 길 또는 배치 칸
- **맵 = 알파벳 a~z 26개** (사용자가 엑셀로 그림: `docs/map유형.xlsx`, 초록 칸 = 길, 흰 칸 = 배치, S/E = 입구/출구)
  - `npm run maps` 가 엑셀을 읽어 `packages/defense/src/maps.ts` 를 만듦. 맵을 고치면 엑셀 수정 → `npm run maps` → `npm run calibrate`
  - **탄 순서 = 쉬운 맵 → 어려운 맵** (확정 2026-11-27, 알파벳 순은 난이도와 무관). 맵 하나당 4탄, 104탄 뒤엔 처음부터 다시
  - 맵 난이도는 `npm run rank-maps` 가 측정: 맵마다 같은 탄 구성(15·35·55탄)을 기준 덱으로 돌려 버티는 몬스터 체력 비교 → `mapOrder.ts`
  - 측정 결과: **길이 짧고 꺾임이 적을수록 어려움** (몬스터가 사거리 안에 머무는 시간이 짧음). 쉬운 쪽 w·q·m·b·r … 어려운 쪽 … c·u·l. x 는 꺾임 14번이라 오히려 쉬운 편(8번째)
  - 그 위에 탄별 체력 보정이 다시 맞춤 → 맵 순서를 바꾼 뒤 체력 곡선이 매끈해짐(예: 10탄 33% → 82%)
- **탄 고르기 화면 (2026-11-27):** 100칸 격자 대신 풀밭 위 구불구불한 길에 탄이 동그라미로 놓인 지도 (**아래 = 1탄, 위 = 100탄** — 아래에서 위로 올라가며 진행, 2026-11-27). 맵이 바뀌는 4탄마다 띠 + "맵 Q · 1~4탄" 표지판, 깬 탄 초록 ✓, 다음 할 탄 금색 반짝, 우두머리 탄 크고 빨갛고 왕관, 못 여는 탄 회색 자물쇠. 열면 다음 할 탄이 가운데로 스크롤
- **탄 준비·진행 화면 (2026-11-27):** 판은 화면 위에 고정, 아래(PC 는 옆) 목록만 스크롤
- **판 그림 (확정 2026-11-27):** 진행 중엔 네모 칸 없이 풀밭 + 부드러운 길 + 입구(파란 굴)·출구(빨간 구멍). **배치할 때만** 배치 칸 네모와 길 방향 화살표를 보여 줌
  - 맵마다 길 15~39칸 · 배치 24~48칸. 짧고 단순한 맵(l·t·c·j)은 길에 안 닿는 배치 칸이 많음 — 체력 보정이 난이도를 맞춤
- 몬스터는 길 위를 끊김 없이 이동 (위치 = 길 위 거리). 칸은 배치·사거리 계산용. 겹칠 수 있음, 빠른 몬스터는 앞지름
- 화면 흐름: **탄 고르기 → 탄 준비(출연 몬스터·능력치·특수능력 보고 덱 배치, 시간 제한 없음) → 게임 시작(자동 진행, 일시정지·배속) → 결과**
- 출전 최대 10명 (확정 2026-11-26, 설정에서 변경), 한 칸에 한 명. **같은 그림·같은 특수능력이어도 여러 명 출전 가능** (확정, 그림은 성능과 무관)
- 목숨 20, 몬스터가 출구에 가면 깎임. 0이 되면 실패
- **몬스터는 출구(E) 칸 가운데에 닿으면 사라짐** (확정 2026-11-27). 판 밖·옆 칸으로 걸어 나가지 않으므로 E 는 판 어디에 둬도 됨 (가장자리가 아니어도, 어느 방향에서 들어와도)
- 공격 대상: 사거리 안에서 가장 앞선(출구에 가까운) 몬스터. 사거리 모양 마름모 (*임시*, 설정에 사각형)

## 3. 탄 (확정 + 임시 수치)
- **1~100탄 + 101탄부터 무한.** 공식으로 생성 (`stages.ts`). **70탄쯤 엄청 어렵게**
- 10탄마다 우두머리 탄 (일반 몬스터 60% + 우두머리)
- **체력은 기준 덱으로 보정 (확정 2026-11-26).** 기준 덱 = 특수능력 없는 10명. 1탄은 능력치 모두 최하, **70탄은 모두 최고**, 그 사이는 10명 합계(공격력·공속·민첩)가 고르게 오르고 사거리 2칸짜리가 한 명씩 늘어남 (`reference.ts`)
  - n탄 체력 = n탄 기준 덱이 자동 배치로 **목숨 절반(10)을 남기고 겨우 깨는 최대 체력**. 몬스터가 적은 탄(1탄 10마리)은 "잃을 수 있는 목숨 전체의 절반"까지만 놓쳐야 통과 (*임시 보완*)
  - `npm run calibrate` 가 시뮬로 찾아 `stageHp.ts` 표(정수)로 저장. **규칙·몬스터·맵을 바꾸면 다시 실행** (테스트가 표가 맞는지 확인)
  - 71탄부터(무한 포함) 70탄 체력에서 탄마다 +3% (확정). 능력치 최고 덱도 특수능력 없이는 못 깸 — 10명 모두 최고 능력치는 사실상 불가능하므로 70탄 근처부터는 특수능력 조합이 필요
  - 우두머리 탄·몬스터 능력이 센 탄은 배율이 낮게 나와 자동으로 같은 난이도가 됨
- *임시 수치:* 몬스터 기본 체력 비율 보통 60·날쌘돌이 40·단단이 200·우두머리 700 (× 탄별 배율), 방어 +1/10탄, 마릿수 10→35, 3탄부터 날쌘돌이, 6탄부터 단단이, 몬스터 민첩 25탄마다 +1
- 난이도 확인(`SIM=1 npx vitest run`, 단순 배치): 최저 덱 27 · 평균 덱 40 · 능력치 최고 덱 71 · 무작위 덱 40~50 · 무작위 덱 전원 특수능력 42~55

## 4. 캐릭
### 기본 능력치 (확정: 4개를 각각 따로 균등하게 뽑음)
| 능력치 | 범위 | 비고 |
|---|---|---|
| 공격력 | 10~30 (*임시*) | 피해 = 공격력 − 몬스터 방어력 (최소 1) |
| 사거리 | 1~2칸 (*임시*) | |
| 공속 | 1~5, 같은 확률 (확정 2026-11-26) | 공속 N = 1초에 N대 (1 = 1초 간격 … 5 = 0.2초 간격). 레벨업 중엔 최대 8 (확정) |
| 민첩 | **5~10 (확정)** | 레벨업으로 11~13까지 |

### 캐릭 모습 (확정 2026-11-27)
- 동물 대신 **헬멧 쓴 사람.** 모두 헬멧을 씀 (능력이 있든 없든)
- **헬멧 색 = 능력치 점수 등급.** 점수 0~100 = 공격력·사거리·공속·민첩을 각각 범위 안에서 0~25점으로 바꿔 더함 (`roster.ts` statScore/statTier). 레벨업 버프는 반영 안 함(원래 능력치)

| 헬멧 | 점수 | 뽑힐 확률(대략) |
|---|---|---|
| 회색 | 0~34 | 22% |
| 초록 | 35~49 | 27% |
| 파랑 | 50~61 | 23% |
| 보라 | 62~74 | 17% |
| 주황 | 75~87 | 8.5% |
| 금(반짝) | 88~100 | 2.4% |

- **특수능력 = 손에 든 도구** (없으면 맨손): 스턴 뿅망치 · 광역공격 폭탄 · 2배 데미지 칼 · 장애물 삽 · 출발지로 보내기 부메랑 · 아군 레벨업 깃발 · 전체 공격 마법 지팡이 · 맹독 독 병. 공격하면 팔을 들어 휘두름
- 예전 "그림 8종(성능 무관)" 규칙은 없어짐 — 데이터의 `image` 칸은 남아 있지만 화면엔 안 씀

### 민첩 (확정)
- **명중률 = 내 민첩 ÷ (내 민첩 + 몬스터 민첩).** 몬스터 입장에선 회피율. 예) 나 11 · 몬스터 8 → 11/19 ≈ 58%
- 몬스터 기술(얼리기·날려 보내기·약화)을 피할 확률도 같은 식 (확정)
- 화면엔 "민첩 N"만 표시 (몬스터별 명중률 표시는 안 함)

### 특수능력 (확정, 원문 [spec](spec))
- 캐릭당 **0~1개**, 붙을 확률 **30%** (30~40% 중, 설정에서 변경). 붙으면 8종 **균등**, 수치도 각각 **균등**
- 모두 **공격할 때 발동, 빗나가도 발동**. 쿨타임은 능력 종류마다 고정

| # | 능력 | 뽑는 수치 | 쿨타임 |
|---|---|---|---|
| 1 | 스턴 | 확률 5/10/15% · 시간 0.5/1/1.5초 | 3초 |
| 2 | 광역공격 (맞힌 자리 중심 **5×5**, 2026-11-27) | 확률 3/5% | 없음 |
| 3 | 2배 데미지 (공격력×2 − 방어력) | 확률 5/10% | 없음 |
| 4 | 장애물 추가 (길 무작위 칸, 중첩 안 됨) | 확률 5/10% · 종류(가시/늪) · 세기(가시 = 1초마다 몬스터 최대 체력 10/20% *해석 임시*, 늪 = 속도 −40/50/60%) | 판당 1회 |
| 5 | 출발지로 보내기 (우두머리도, 면역이면 안 됨) | 확률 3/5% | 20초 |
| 6 | 아군 전체 레벨업 | 확률 5% · 능력치(공격력/사거리/공속/민첩/전체) · +1/+2/+3 | **20초** |
| 7 | 전체 공격 | 확률 2/3/4/5% · 맵 위 몬스터 전부에게 공격력 − 방어력 (광역공격처럼 명중 판정 없음, 무적엔 안 들어감, 몬스터 능력 판정은 원래 대상만 — *임시 해석*) | **1초** |
| 8 | **맹독** (2026-11-27) | 확률 5/10% · 1초마다 공격력의 20/30/40% (방어 무시, 몬스터당 한 번, 중첩 없음, 죽을 때까지, 보라색 표시) | 없음 |

- *임시 값:* 스턴 풀린 뒤 1초 면역 · 장애물은 탄 끝까지 · 레벨업 5초, 1단계 = 공격력 +2 / 사거리 +1(3단계 +2) / 공속 +1(확정) / 민첩 +1

## 5. 몬스터
### 몬스터 12종 (확정 2026-11-27, 사용자 docs/spec)
- 능력치 4가지(**체력·방어·민첩·속도**) 조합: 보통 1 + 한 가지 높은 4 + 두 가지 높은 6 = 11 + **우두머리(3가지 이상 섞음)** = 12
- 수치는 *임시* (`stages.ts` MONSTER_BASES). 체력은 종류끼리의 비율이고 탄별 체력 배율을 곱함. 빠르거나 민첩하면 체력이 낮고, 체력·방어가 높으면 느림

| 종류 | 높은 것 | 체력 | 방어 | 민첩 | 속도(칸/초) | 처음 나오는 탄 (*임시*) |
|---|---|---|---|---|---|---|
| 보통 | — | 60 | 2 | 5 | 1.0 | 1 |
| 날쌘돌이 | 속도 | 40 | 1 | 6 | 1.8 | 3 |
| 단단이 | 방어 | 70 | 7 | 4 | 0.85 | 6 |
| 튼튼이 | 체력 | 140 | 2 | 5 | 0.85 | 9 |
| 날렵이 | 민첩 | 50 | 2 | 10 | 1.0 | 12 |
| 철벽이 | 체력·방어 (놓치면 목숨 −2) | 110 | 5 | 4 | 0.75 | 20 |
| 기사 | 방어·속도 | 50 | 5 | 5 | 1.4 | 24 |
| 돌진이 | 체력·속도 | 80 | 1 | 5 | 1.4 | 28 |
| 바람이 | 민첩·속도 | 40 | 1 | 8 | 1.5 | 32 |
| 방패꾼 | 방어·민첩 | 60 | 5 | 8 | 0.9 | 36 |
| 끈질이 | 체력·민첩 | 95 | 2 | 8 | 0.9 | 40 |
| 우두머리 | 탄마다 3가지(50탄부터 4가지) 섞음 — 섞인 것마다 체력 ×1.4 · 방어 +3 · 민첩 +3 · 속도 ×1.3 | 700 | 5 | 6 | 0.7 | 10의 배수 탄 (놓치면 목숨 −5) |

- 한 탄에 나오는 종류: 열린 종류 중 최대 (2 + 탄/20)종, 그 탄에 처음 열리는 종류는 꼭 나옴(새 몬스터 소개), 마릿수는 종류끼리 고르게
- 탄이 오를수록 방어 +1/10탄, 민첩 +1/25탄, 속도 조금씩 (전 종류 공통)

### 몬스터 그림 (확정 2026-11-27)
- **슬라임 1종 + 입은 소품으로 특성 표시.** 체력 = 배낭, 방어 = 갑옷, 민첩 = 깃털 모자, 속도 = 운동화 → 두 가지 높은 종류는 소품 두 개. 우두머리 = 왕관 + 망토. 종류마다 몸 색도 다름
- 몬스터 능력용 소품 시안(목도리·꽃 머리핀·버섯 모자·날개·스프링·천사 고리·부채·먹물 붓·소라 껍데기 등)은 그려 둠 — "능력자" 표시에 쓸지 미정

- 몬스터는 캐릭을 때려 쓰러뜨리지 않음 (캐릭 체력 없음). **방해만** (확정)
- 몬스터 "면역" 성질 칸 있음 (지금은 아무도 없음)
### 몬스터 특수능력
- 확정: 몬스터에도 특수능력이 있고, 탄 준비 화면에 공개. 원문은 [spec](spec) "몬스터 스펙"
- 확정 (2026-11-26): **모두 캐릭에게 공격받을 때(빗나가도) 판정** · "판당 N회"는 **몬스터 한 마리마다** · 캐릭에게 거는 것(얼리기·날려 보내기·약화)은 **민첩으로 피할 수 있음** (내 민첩 ÷ (내 민첩 + 몬스터 민첩)) · 예전 단단해지기는 9번째로 남김

| # | 능력 | 효과 | 확률 | 제한 |
|---|---|---|---|---|
| 1 | 얼리기 | 몬스터 칸 중심 3×3 캐릭 1초 공격 못 함 | 30% | 쿨 2초 · 풀린 캐릭 3초 면역(*임시*) |
| 2 | 완전 회복 | 체력 전부 회복 | 20% | 마리당 1회 |
| 3 | 전체 회복 | 판 위 몬스터 전체 최대 체력 10% 회복 | 10% (*임시*, spec 에 확률 없음) | 마리당 1회 |
| 4 | 질주 | 이동속도 2배, 3초(*임시*) | 10% | 마리당 1회 |
| 5 | 순간이동 | 앞으로 3칸. 출구 바로 앞 칸 가운데까지만(*임시*, 출구 칸에 닿으면 사라지므로) | 10% | 마리당 2회 |
| 6 | 무적 | 2초 동안 피해·스턴·출발지로 보내기·가시 안 통함 | 5% | 쿨 10초 |
| 7 | 날려 보내기 | 때린 캐릭을 무작위 빈 배치 칸으로 (탄 끝나면 원래 배치) | 3% | 쿨 5초 |
| 8 | 약화 | 때린 캐릭 5초 공속·명중률 절반 | 10% | 쿨 20초 |
| 9 | 단단해지기 | 3초 방어력 + (4 + 탄/10) | 100% | 쿨 10초 |

- 대상이 없으면(얼릴 캐릭 없음·빈칸 없음·더 갈 곳 없음) 발동 안 한 것으로 쳐서 쿨타임·횟수를 안 씀
- 한 공격에 능력이 여럿이면 순서: 무적 → 완전 회복 → 전체 회복 → 질주 → 순간이동 → 얼리기 → 날려 보내기 → 약화 → 단단해지기
- 등장 단계 (*임시*): 1~9탄 우두머리만(단단해지기) / 10~29 한 종류 / 30~49 두 종류 / 50~69 전 종류 1개 / 70~ 전 종류 2개씩 (9종 중 무작위, 겹치지 않게)

## 6. 성장 · 뽑기 · 변경 (확정)
- 강해지는 길 세 가지: **탄 보상**(캐릭 추가권·변경권·화폐 등) · **광고 보상** · **과금**. 모아서 원할 때 씀
- **캐릭 추가권** = 뽑기 1번
- 변경권은 둘로 나뉨. 그림은 늘 그대로

| 권 | 하는 일 |
|---|---|
| 능력치 변경권 · 보통 | 4개 전부 다시 |
| 능력치 변경권 · 상급 | 1개 골라 유지 + 3개 다시 |
| 능력치 변경권 · 최상급 | 2개 골라 유지 + 2개 다시 |
| 능력치 변경권 · 럭키 | 능력치마다 두 번 굴려 좋은 쪽 (최대치 그대로). **지금은 안 만듦, 자리만** |
| 특수능력 변경권 | 특수능력만 다시 (7종·수치 새로). 없어지지 않음. **특수능력 없는 캐릭엔 못 씀** |

- 특수능력 없는 캐릭에 능력치 변경권을 쓰면 **5%** 확률로 특수능력이 생김 → 7종 균등(각 1/7) → 수치도 하나씩 균등
- 모든 뽑기·변경 무작위는 **균등**
- **이름 통일 (2026-11-27):** 뽑기권 · 능력치 변경권(보통/상급/최상급) · 특수능력 변경권 ("교환권"이라는 말은 안 씀). spec 의 "상급" = 위 표의 "고급", "최상급" = "최고급"
- **첫 시작 지급 (확정):** 뽑기권 5 · 특수능력 변경권 1 · 능력치 변경권(보통) 3
- **캐릭 합성 (확정):** 캐릭 3명 → 능력치 변경권(보통) 1 · 5명 → 뽑기권 1 · 8명 → 능력치 변경권(상급) 1 · 10명 → 특수능력 변경권 1 · 12명 → 능력치 변경권(최상급) 1
  - 캐릭이 늘어나는 길은 뽑기권뿐이라 탄 보상(특히 뽑기권)이 중요. 합성 화면엔 좋은 캐릭을 실수로 넣지 않게 확인 단계 필요
- 미정: 탄 보상 표(첫 클리어/반복, 우두머리 탄), 광고 하루 횟수, 화폐 종류, 보관함 크기, 거래 규칙(수수료·제한)

## 7. 서버 (방향 확정, 미구현)
- 서버가 가지는 것: 캐릭 목록 · 화폐 · 권
- 뽑기·변경 난수는 **서버에서** (앱에서 굴리면 조작 가능)
- 탄 결과는 앱이 **탄 번호 + 배치**만 보냄 → 서버가 같은 엔진으로 다시 돌려 판정·보상
- 광고 보상은 광고 회사의 서버 확인으로만 지급, 거래도 서버에서
- 예전 프로젝트의 Supabase 구조(`game.war/supabase`, `game.war/apps/mobile/src/online`) 참고. 비밀 키는 절대 앱·커밋에 넣지 않음

## 8. 그림 (확정: 그림은 코드로 그려 스프라이트로)
- `scripts/sprites/art.mjs` 에 SVG 코드로 그림 → `npm run sprites` 로 시트(PNG) 생성 → 게임이 개체마다 따로 애니메이션
- 지금 그림(헬멧 쓴 사람 6색 + 도구 8종, 슬라임 몬스터 12종)은 **임시 그림.** 사용자가 그림 가이드를 주면 다시 그림
- 성능: 200개 60fps, 1000개 60fps, 2000개 29fps (PC 크롬). 휴대폰은 확인 전
