     - 몬스터에 "면역" 성질 칸 추가(지금은 아무도 없음) → 출발지 보내기·스턴 등을 막을 수 있음
     - 명중률 → **민첩**(70~100). 맞힐 확률 = 민첩% − 회피력, 얼리기 피할 확률 = 민첩 − 60 (임시, 사용자가 수치 정할 예정). 덱 화면에 몬스터별 맞힐 확률 + 얼리기 피할 확률 표시
     - 화면: 발동하면 몬스터 위에 능력 이름, 2배는 빨간 "N!!", 가시(▲ 빨강)·늪(≈ 파랑) 장애물 칸, 스턴 ★, 얼리기 피하면 "피함!", 상단에 레벨업 중인 능력치
     - 테스트: 6종 모두 발동·장애물 판당 1회·스턴·출발지 확인, 결정성. 난이도 곡선(특수능력 없음)은 그대로 (평균 덱 ~38탄, 최고 덱 57탄)
15. 민첩 수치 확정: 캐릭 민첩 5~10 (최대 10, 레벨업으로 11~13 가능). 몬스터도 민첩. **명중률 = 내 민첩 ÷ (내 민첩 + 몬스터 민첩)**, 몬스터 입장에선 그게 회피율 (예: 나 11 · 몬스터 8 → 11/19 ≈ 58%). → 반영 작업
   - 결과: 반영 완료. 캐릭 민첩 5~10, 레벨업 민첩 +1/+2/+3(→ 11~13), 몬스터 회피력 → 몬스터 민첩(임시: 보통 5·날쌘돌이 9·단단이 3·우두머리 6, 25탄마다 +1). 명중률 = 내 민첩 ÷ (내 + 몬스터). 얼리기 피할 확률도 같은 식(임시 해석). 덱 화면에 몬스터별 명중률·얼리기 피할 확률 표시. 난이도 곡선 거의 그대로 (평균 덱 ~35탄, 최고 덱 54탄)
